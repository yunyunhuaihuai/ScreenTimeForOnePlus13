# 屏幕时间 ScreenTimeLog

Android 端自建的屏幕使用时长 + 耗电记录器。针对**用「冰箱」冻结应用后系统自带数字健康不再统计时长**的场景，从底层重建完整数据，冻结应用照样显示。

> 个人自用项目，目标设备 OnePlus 13（ColorOS 15 / Android 15），依赖 KernelSU root 才能发挥全部能力。

## 为什么需要它

ColorOS 的数字健康在应用被冻结（`pm disable-user`）后，会在**展示层**过滤掉这些应用的时长——数据其实还在系统里，只是不给你看。本项目结合以下数据源重建记录：

| 层 | 来源 | 用途 |
|---|---|---|
| 1 | `UsageStatsManager.queryEvents` | 会话时间线（ColorOS 会裁剪，不可靠） |
| 2 | root 读取系统 daily 原始文件及独立归档 | 毫秒级历史事件，按自然日自动回补 |
| 3 | root 跑 `dumpsys usagestats` | 最近24小时事件，补尚未落盘的尾段 |
| 4 | 独立 root 采集器保存 `batterystats` 快照 | 每 UID / 每组件耗电，App恢复后顺序导入 |

## 功能

- 每日总量 + 日期切换、按分类堆叠的小时柱状图（点柱子看该小时构成）、全天会话色带
- 拿起与解锁：每日拿起次数、解锁后 15 秒内最常打开的应用
- 应用排行：时长 / 耗电双模式，后台占比标注
- 应用明细：分类可手动修正、全部会话起止记录
- 周报 / 月报 / 年报：周期完整结束后自动生成正式报告并推送通知（上一个完整周/自然月/自然年），支持手动生成当前周期预览
- 暗色模式、模块顺序自定义

## 数据安全与准确性口径

- 当前版本 v0.19.0（versionCode 35）；长期历史数据优先：Room schema 版本化（`app/schemas/`，当前 v10），升级必须走显式 Migration，**没有销毁式迁移兜底**——v4+ 升级缺迁移会显式失败而不是清库
- **采集独立运行**（v0.19）：KernelSU开机脚本启动root采集器，APK被强停后仍可留存；熄屏目标10分钟、亮屏目标2分钟，不持全时唤醒锁，实际间隔仍受系统暂停影响。设置中可停用/重新启用。
- **历史自动回补**（v0.19）：校验系统文件与归档的版本、时间、映射和SHA，完整范围才允许替换；保留窗口两侧历史会话，拿起/首开仅按认证完整自然日替换。使用历史目标归档30天，耗电帧目标保留8天，空间上限优先，丢弃记录可查。详见 [ROOT_COLLECTOR.md](ROOT_COLLECTOR.md)。
- UI 与报告共用同一 "effective usage" 口径（逐包逐日 max(会话, 系统回补值)），报告总量/Top 与首页完全一致
- 耗电差分在单一数据库事务内提交（快照推进放最后），进程中途被杀不会出现"快照已推进、日汇总未写入"的丢数据窗口
- **耗电记账 = 原始观测与已入账高水位分离**（v0.18）：增量一律相对"已入账高水位"计算，同 epoch 的模型回算（累计值小幅回落）不会在恢复时二次入账；任何有限正增量都落库，不因阈值被吞
- **采集健康可核验**：首页分别显示时长成功时间、耗电观测、后台心跳与当日覆盖；历史缺口不会被新一次成功清除。临时故障有限重试，独立进程尽力发限频本地告警；采集器自身停止时仍需App或开机脚本恢复。
- **归属不随安装状态漂移**（v0.18）：采集时持久化 UID→包名成员存档，历史耗电按"该日有效"归属解析——卸载保留历史、UID 复用不错挂、共享 UID 不拆分猜归属
- 耗电为**模型估算**：`dumpsys batterystats` 的每 UID/组件 mAh 由"计时器时长 × power_profile 固定电流"得出，非独立实测；报告标注"应用归因耗电（UID 模型估算，非整机实际耗电）"，Actual−Computed 缺口不按比例摊给任何 App
- 使用时长以原始系统事件重建为权威，历史文件优先、实时dump补尾；打开轮次显示"真实使用时长"（会话区间并集），合并轮次只影响"打开 N 次"计数

## 技术栈

Kotlin + Jetpack Compose (Material 3) + Room + WorkManager + libsu，无 NDK。minSdk = targetSdk = 35。
工具链：JDK 21 / Gradle 8.9 / AGP 8.7.3 / Kotlin 2.0.21。

## 构建

使用仓库自带的 Gradle Wrapper（8.9）：

```bash
export JAVA_HOME="<JDK 21 安装路径>"
./gradlew.bat :app:assembleDebug   # Windows
# 或 ./gradlew :app:assembleDebug  # Git Bash
adb -s "$ADB_SERIAL" install -r app/build/outputs/apk/debug/app-debug.apk
```

首次使用需在系统设置中手动授予「使用情况访问」权限（ColorOS 禁止 shell 授权 appops）。
